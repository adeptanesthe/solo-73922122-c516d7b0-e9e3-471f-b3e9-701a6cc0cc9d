# 误报相似走势检索 · 历史回放

一次误报发生后，班长要在逐分钟模型分数记录里找出**走势相似**的其他片段，安排
复核。本工具上传分数 CSV 后，在回放页框选误报样本的起止分钟，自动检索等长片段、
计算受限 DTW 距离，并在复核名额内给出互不重叠的候选名单；名单中的片段标为
已复核后，系统用原查询在全部候选上重选并更新名单与标记。

## 规则约定

- **样本**：回放页填写起止分钟，闭区间连续片段，长度 8～30 分钟。
- **候选**：在当前 CSV 上滑动取与样本等长的窗口；与样本段相交（含样本自身）
  的窗口一律排除。
- **归一化**：样本与每个候选各减去**本段首分钟**的分数，只比较走势形状，
  不受整体分数高低影响。
- **距离**：动态时间规整（DTW）求最小累计绝对差；规整路径上对齐的两个位置
  在各自片段内的偏移量之差**不得超过 2 分钟**（Sakoe-Chiba 带）。距离必须
  不超过填写的距离上限。
- **名单选择**：候选之间互不重叠，且不得与任一已复核区段相交；在复核名额
  （1～10）内**先尽量多选片段，数量相同时取总距离最小的一组**（再相同按下标
  字典序，结果可复现）。
- **复核重选**：把名单中一段标为已复核后，用原查询参数从**全部候选**重选；
  重选后若选不出任何片段则判定失败，**回滚本次标记并保留原名单和原有标记**。
- **失效处理**：成功换 CSV 或清空回放后，名单与标记一并清除；从旧列表提交
  复核会提示重新检索。

docker compose up --build

## 网页演示步骤（实测）

1. 首页点 **下载示例 CSV**（或用仓库根目录的 `sample_data.csv`，720 行，
   分钟 1～720），在“① 上传”处选择该文件上传，页面提示：
   `已加载 sample_data.csv：720 行，分钟 1 ~ 720，分数 …`，并提示旧名单与
   复核标记已清空。示例数据在分钟 40～51 植入误报原型，90、150、210、270、
   330/338、400、540、610、680 等处植入相似走势（含带噪、峰值晚 1 分钟的
   时间微移版本），470～481 植入一条反向走势负例。
2. 在“② 检索条件”填：样本起始 `40`、结束 `51`（12 分钟）、距离上限 `20`、
   复核名额 `10`，点 **检索相似片段**。实测：
   - 候选 **14** 段，名单入选 **9** 段，总距离 **108**；
   - 名单为 90~101（11）、150~161（16）、210~221（11）、270~281（15）、
     338~349（7）、400~411（15）、540~551（16）、610~621（9）、680~691（8）；
   - 330~341（距离 23）虽满足上限，但与 338~349 相交且后者距离更小，
     互斥选择后落选，可在“全部候选”展开项中看到“未入选（重叠/名额）”；
   - 反向走势 470~481 的受限 DTW 距离为 **137**，远超上限，不进候选。
3. 在“④ 候选与复核名单”点第一段（90~101）旁的 **标为已复核**：
   页面提示已标记并按原查询从全部 14 个候选重选，新名单 **8** 段（90~101
   不再出现），“⑤ 已复核区段”新增 1 条，回放图上出现紫色复核带。
4. 演示**重选失败回滚**：把距离上限改为 `8` 重新检索（候选 2 段：338~349
   距离 7、680~691 距离 8，名单 2 段）。先复核 338~349，名单剩 1 段；
   再复核 680~691，此时全部候选均与已复核区段相交、重选为空，页面提示
   `重选失败……已保留原名单和原有标记，该次复核未生效`，名单仍为 1 段、
   已复核区段不增加。
5. 演示**名额与上限**：重新检索上限 `20`、名额 `3`，名单只保留数量上限内
   总距离最小的 3 段（338、610、680）；上限改为 `8`、名额 `10` 时仅 2 段
   候选入选。
6. 演示**失效保护**：重新上传同一 CSV（或点 **清空回放**）后，名单与标记
   清空；此时若用浏览器里残留的旧表单提交复核，页面提示
   `该名单已失效……请用当前参数重新检索后再提交复核`。
7. “③ 分数回放”图中红色带为样本、淡蓝带为全部候选、绿色带为当前名单、
   紫色带为已复核区段；拖动滑杆可逐分钟回放分数。

## 输入格式与校验

- **CSV**：两列 `分钟号,整数分数`（可含表头）；分钟号连续（步长 1）；
  最多 3000 行。
- **样本**：起止分钟都在数据范围内，起点不晚于终点，长度 8～30 分钟。
- **距离上限**：≥ 0 的整数（累计绝对差，分数为整数故距离也是整数）。
- **复核名额**：1～10 的整数。

## 算法说明

- **受限 DTW**：`D[i][j] = |a_i-b_j| + min(D[i-1][j], D[i][j-1], D[i-1][j-1])`，
  仅在 `|i-j| ≤ 2` 的格点上转移，答案 `D[n-1][n-1]`；两段等长（n≤30），
  单窗比较 O(n²)。
- **候选检索**：最多 3000 个等长滑动窗口，逐窗归一化 + DTW，满负荷
  （3000 行、30 分钟样本）实测秒级完成，页面显示 DTW 耗时。
- **名额选择**：带基数维的加权区间调度 DP。`prev[i]` 为终点严格小于候选 i
  起点的最近候选，`f[i][k]` 表示只看前 i 个候选、至多取 k 个时的最优
  （数量, 总距离, 下标元组）；数量优先、总距离最小、下标字典序兜底，
  复杂度 O(n·quota)。
- 正确性由 `tests.py` 交叉验证：受限 DTW 对独立朴素实现、选择 DP 对
  全子集枚举（400 组随机），以及网页端检索/复核/回滚/失效全流程。

## 文件

| 文件 | 说明 |
| --- | --- |
| `core.py` | 归一化、受限 DTW（带宽 2）、候选检索、名额选择 DP |

| `templates/index.html` | 单页界面（上传、检索、回放、名单、已复核区段） |
| `sample_data.py` / `sample_data.csv` | 含多条相似走势的示例数据生成器与成品 |
| `tests.py` | 自测：朴素 DTW / 全子集枚举交叉验证 + 网页端冒烟测试 |
| `Dockerfile` / `docker-compose.yml` | 容器化启动 |

## 已知限制

- 会话数据保存在单进程内存中，重启即清空；多副本部署需改用共享存储。
- 分钟号必须连续，缺口数据会被拒绝而不做插值。
- DTW 采用绝对差累计值且带宽固定为 2；若以后需要均值归一化或可调带宽，
  需扩展 `core.normalize` 与检索表单。
